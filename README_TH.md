# ML Studio — Chutipong

เว็บแอป Machine Learning สำหรับโครงงาน 6 เทคนิค พัฒนาด้วย Python และ Streamlit

## รูปแบบเว็บไซต์
เวอร์ชันนี้ปรับดีไซน์ใหม่เป็นธีมสีเขียวธรรมชาติ (Forest & Mint) ใช้แถบเมนูสีเขียวอ่อน การ์ดพื้นขาว และแบนเนอร์ทรงเรขาคณิต เพื่อให้แตกต่างจากตัวอย่าง แต่คงเมนูและขั้นตอนการใช้งานโมเดลไว้

## 6 เทคนิคในโปรเจกต์
1. K-Nearest Neighbor — สาธิตการจำแนกความเสี่ยงโรคหัวใจ
2. Decision Tree — จำแนกประเภทไวน์
3. Support Vector Machine — ทำนายแนวโน้มการยกเลิกบริการ
4. K-Means — จัดกลุ่มดอก Iris
5. Regression — ประมาณราคาบ้าน
6. Random Forest — ทำนายแนวโน้มสอบผ่าน

## วิธีเปิดใช้งานในเครื่อง
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy บน Streamlit Community Cloud
1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้น GitHub
2. เข้า https://share.streamlit.io/
3. เลือก repository และ branch ที่อัปโหลด
4. ตั้งค่า Main file path เป็น `app.py`
5. กด Deploy

## ข้อควรทราบ
ข้อมูลโรคหัวใจ ลูกค้า ราคาบ้าน และผลการเรียนเป็นข้อมูลสังเคราะห์เพื่อการศึกษา ไม่ใช่ข้อมูลจริงและไม่ควรใช้ตัดสินใจในชีวิตจริง ส่วน Wine และ Iris ใช้ชุดข้อมูลตัวอย่างจาก scikit-learn
